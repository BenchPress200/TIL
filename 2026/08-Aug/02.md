- 리트코드<br>
**[[Best Sightseeing spot](https://leetcode.com/problems/best-sightseeing-pair/description/) - 20:53]**<br>
    - 관광 명소 값 배열 values
        - 2 <= values.length <= 50,000
        - 1 <= values[i] <= 1,000
    - 두 개의 관광 명소를 선택했을 때 점수 도출 가능
        - values[i] + values[j] + i - j (i < j)
    - 관광 명소 쌍의 점수 최댓값 반환

    values의 최대 길이가 50,000이기 때문에 O(n^2)으로 풀이하면 시간 초과가 예상됩니다. 현재 인덱스 j가 고정되어 있다고 했을 때 최댓값은 j미만 인덱스에서 values[i] + i 의 최댓값입니다. 이러한 특성을 이용하여 values를 순회하면서 values[i] + i값을 갱신하고, 현재 인덱스를 j로 보고 계산하여 풀이했습니다.
