- 리트코드<br>
**[[Minimum Number of Work Sessions to Finish Tasks](https://leetcode.com/problems/minimum-number-of-work-sessions-to-finish-the-tasks/description/) - 40:00+]**<br>
    -  n개의 작업 수행 시간을 담은 tasks 배열
        - tasks[i]: i번째 작업의 수행 시간
        - 1 <= n <= 14
        - 1 <= tasks[i] <= 10
    - 연속으로 작업 수행할 수 있는 최대 시간 sessionTime
        - max(tasks[i]) <= sessionTime <= 15
    - 주어진 작업들을 끝내는 조건
        - 세션 내에서 시작한 작업은 반드시 같은 세션에서 끝내야 함
        - 이전 작업 끝내면 즉시 다음 작업 시작 가능
        - 작업 완료 순서 노상관
    - 모든 작업을 끝내기 위한 최소 세션의 개수 반환

    작업들을 오름차순 정렬하고 작은 애들끼리 묶어서 처리하면 반례가 존재합니다. 따라서 각 작업의 완료 상태를 비트마스크로 표현하고 dp를 통해 각 마스크에서 사용한 최소 세션 수와 마지막 세션에서 사용한 시간을 기록하여 풀이했습니다.
