# 2026-08-20 TIS
## 타이틀: [Min Cost to Connect All Points](https://leetcode.com/problems/min-cost-to-connect-all-points/description/)
> 풀이 시간: 25분 

<br>

## 문제 요구 사항
2차원 좌표 배열 points가 주어집니다.
- 1 <= points.length <= 1,000
- -1,000,000 <= x, y <= 1,000,000
- 모든 좌표쌍은 구분됨

두 좌표의 연결 비용은 맨해튼 거리로 계산합니다. 
- |xi - xj| + |yi - yj|

모든 점들을 직간접적으로 연결했을 때 최소 비용을 반환하는 문제입니다.

<br>

## 풀이
모든 점들을 간접적으로 연결하면서 최소 비용으로 연결하는 MST 문제입니다. 
1. 각 점들을 points의 인덱스로 넘버링
2. points 2중 순회하면서 간선 리스트 할당
3. 간선 리스트를 비용 오름차순으로 정렬
4. 전체 좌표가 n개라고 했을 때, 선택한 간선이 n-1이 될 때까지 간선 리스트 순회하면 선택
    - 이때, 연결하려는 두 좌표가 싸이클을 유발하지 않도록 유니온 파인드 활용
5. 간선 선택하면서 누적한 비용 반환
