- 리트코드<br>
**[[Most Profitable Path in a Tree](https://leetcode.com/problems/most-profitable-path-in-a-tree/description/) - 40:00+]**<br>
    - 노드 n개 가지는 트리 존재
        - 0 <= 노드 번호 <= n-1
        - 2 <= n <= 100,000
    - 두 노드 사이의 간선 정보 edges
    - 엘리스와 밥이 존재하고, 엘리스는 0(루트)에서 출발, 밥은 인자로 주어지는 bob에서 출발
    - 엘리스는 리프 노드를 향해 이동하고, 밥은 루트 노드를 향해 이동
    - 각 노드가 가지는 값 amount 배열
        - -10,000 <= amount <= 10,000
    - 이동 규칙
        - 매초마다 엘리스와 밥은 각각 인접한 노드 이동
        - 각 노드의 값만큼 비용 처리
        - 누군가 이미 지나왔다면 아무런 비용 계산 안 함
        - 동시에 도착했다면 각각 절반씩 비용 계산
    - 엘리스가 리프 노드에 도달했을 때 얻을 수 있는 최대 수익 반환

    밥은 트리를 거슬러 올라가 루트 노드로 가므로, 유일한 경로를 가집니다. 우선, BFS를 통해 방문 배열에 이전 방문 노드를 기록하면서 밥의 경로를 저장합니다. 이후 밥에서 시작해 방문 배열을 따라올라가면서 밥이 몇 초에 특정 노드에 도착하는지 저장합니다. 그리고 앨리스의 출발점인 0에서 BFS를 시작하여 리프 노드에 도달했을 때 비용 최댓값 갱신을 진행합니다. 앨리스가 다음 노드에 방문했을 때, 밥이 해당 노드를 방문했는지, 몇 초에 지났는지 확인하고 정확한 비용 갱신을 진행해야 합니다.
