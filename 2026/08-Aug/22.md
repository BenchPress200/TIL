# 2026-08-22 TIS
## 타이틀: [Steps to Make Array Non-decreasing](https://leetcode.com/problems/steps-to-make-array-non-decreasing/description/)
> 풀이 시간: 62분 

<br>

## 문제 요구 사항
정수 배열 nums가 주어집니다.
- -1 <= nums.length <= 10,000

한 번의 연산으로 nums[i-1] > nums[i]인 nums[i]를 모두 제거할 수 있습니다. nums 배열이 오름차순 배열이 될 때까지 수행한 연산 횟수를 반환하는 문제입니다.

<br>

## 풀이
이전 수보다 작아야 현재 연산에서 삭제 가능합니다. 삭제가 필요하더라도 이전 수보다 크거나 같다면 추후 스텝에서 삭제해야 합니다. 결과 배열을 구하기 위해 아래 순서로 풀이합니다.
1. 결과 배열에 포함될 오름차순 숫자 인덱스 구하기 => 기준 인덱스
2. 기준 인덱스들의 구간에 존재하는 모든 수는 삭제해야 하는데, 각 구간의 연산 횟수를 구하고 최댓값 갱신
    - 각 구간에서 연산 횟수는 스택을 활용하여 풀이
