- 리트코드<br>
**[[Shifting Letters](https://leetcode.com/problems/shifting-letters/description/) - 26:33]**<br>
    - 소문자로 이루어진 문자열 s
        - 1 <= s.length <= 100,000
    - s와 길이가 같은 정수 배열 shifts
        - 0 <= shifts[i] <= 1,000,000,000
    - shifts[i] = x: 문자열 s에서 i+1번째 문자까지 x번 쉬프트(쉬프트는 아스키값 + 1)
    - shifts의 값을 모두 적용했을 때의 문자열 s 반환

    앞에 위치한 문자들은 여러 shifts 요소들에 영향을 받아 값이 바뀝니다. 효율적인 풀이를 위해 shifts의 반대 방향 누적합 배열을 구하고, s의 각 문자를 순회하면서 26자 이내에 회전하여 변하는 값을 구하여 풀이했습니다.
