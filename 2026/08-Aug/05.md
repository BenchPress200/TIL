- 리트코드<br>
**[[Implement Magic Dictionary](https://leetcode.com/problems/implement-magic-dictionary/description/) - 13:15]**<br>
    - MagicDictonary 클래스 주어짐
    - buildDict 메서드를 통해 문자열 배열 주어짐
        - 1 <= 문자열 배열의 길이 <= 100
        - 1 <= 각 문자의 길이 <= 100
    - search 메서드를 통해 검색할 문자열 주어지고 반환값은 boolean
        - buildDict로 전달한 문자열 중에서, search와 단 하나의 문자만 다른 문자열이 있다면 true 반환, 그렇지 않다면 false 반환
    - 검증 진행 순서
        - MagicDictionary 생성
        - buildDict 호출
        - search 호출해서 반환값 검증(최대 100번 호출)

    클래스를 정의하는 문제입니다. 주어지는 입력 값의 크기가 작기 때문에, buildDict으로 초기화할 때 클래스 변수로 배열을 그대로 저장합니다. 이후 search를 호출했을 때 문자열 배열을 순회하면서 단 하나의 문자만 다른지 검증하고 결과를 반환하도록 풀이했습니다.
