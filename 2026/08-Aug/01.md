- 리트코드<br>
**[[Maximize Spanning Tree Stability with Upgrades](https://leetcode.com/problems/maximize-spanning-tree-stability-with-upgrades/description/) - 40:00+]**<br>
    - 0부터 n-1까지 n개의 정점 존재
    - 2 <= n <= 100,000
    - 간선 정보 배열 edges
    - edges[i] = [u, v, s, must]
    - 1 <= edges.length <= 100,000
    - u와 v는 연결되는 두 정점(무방향)
    - s는 힘
    - must는 필수 여부(1이면 필수, 0이면 옵셔널)
    - 업그레이드 가능 횟수 k
    - 0 <= k <= n
    - 업그레이드는 옵셔널로 선택한 간선의 힘을 최대 한 번 2배로 만들 수 있는 횟수
    - 주어진 그래프 정보로 신장 트리를 만들었을 때 안정성 도출 가능
    - 안정성: 완성한 신장 트리에 존재하는 간선 중에서 최소 힘
    - must=1인 간선을 모두 연결하고, 나머지 옵셔널 간선을 연결했을 떄 완성한 신장 트리의 최대 안정성 반환
    - K번 업그레이드 가능 고려
    - 신장 트리를 만들지 못 한다면 -1 반환

    MST 응용 문제로, 우선 must=1인 간선들을 연결하고 신장 트리가 불가능한지 판단합니다. 이후에 must=0인 간선들을 힘 내림차순 정렬해서 선택하고, 선택된 간선들 중에서 작은 값 순으로 최대 k번 업그레이드하여 트리의 최대 안정성 값을 반환했습니다.
