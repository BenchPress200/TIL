# 2026-08-13 TIS
## 타이틀: [Number of Ways to Arrive at Destination](https://leetcode.com/problems/number-of-ways-to-arrive-at-destination/description/)
> 풀이 시간: 52분 

<br>

## 문제 요구 사항
n개의 도시가 존재합니다. 
- 1 <= n <= 200
- 도시는 0번부터 n-1번까지 존재
- 도시 간 도로가 있고 양방향

도로를 표현하는 이차원 배열 roads이 주어집니다.
- n-1 <= roads.length <= n*(n-1)/2
- roads[i] = [u, v, time]
- u와 v의 도로 이동 시간 time
- 1 <= time <= 1,000,000,000

0번 도시에서 시작해서 n-1번 도시까지 도달하는 최소 시간의 경로를 카운팅하여 반환합니다. 경로의 수가 매우 크면 모듈로 (10^9 + 7)을 수행하여 반환합니다.

<br>

## 풀이
0번부터 시작해 n-1까지의 최소 비용은 다익스트라로 구할 수 있습니다. 해당 경로를 카운팅해야 하므로 다음과 같이 풀이합니다.
1. roads 배열로 이중 연결리스트 타입 그래프 초기화
2. 다익스트라 호출
3. 다익스트라 내부에서 방문 배열, 0번으로부터 시간 배열, 각 최소 비용으로 도달한 경로 개수 카운트 배열 선언
4. 우선순위 큐 할당하고 0번 방문 표시하고 카운트 1로 초기화 후 우선순위 큐에 삽입
5. 우선순위 큐가 빌 때까지 진행
6. 현재 도시 꺼내서 연결된 도시 순회
7. 현재 시간과 다음 도시 도달 시간을 합쳐서 최솟값 갱신 가능한지 확인
    - 갱신 가능하다면 현재 도시 카운트 값으로 경로 개수 할당 및 시간 배열 값 갱신
    - 최소 시간이 같다면 경로 개수를 현재 도시 기준으로 업데이트
8. 다익스트라 수행 후, n-1번 도시의 카운트값 꺼내서 정답으로 반환
