# 2026-08-21 TIS
## 타이틀: [Guess Number Higher or Lower 2](https://leetcode.com/problems/guess-number-higher-or-lower-ii/description/)
> 풀이 시간: 49분 

<br>

## 문제 요구 사항
1부터 n 사이에 있는 숫자 추측 게임을 진행합니다.
- 1 <= n <= 200

게임 진행 방식은 다음과 같습니다.
1. 숫자 추측
2. 맞혔다면 게임 승리
3. 틀렸다면 현재 숫자가 정답보다 큰지 작은지 알 수 있음
    - 잘못된 숫자 x를 추측할 때마다 x 달러 지불
    - 돈을 다 잃으면 게임 패배

정답 숫자가 무엇이든지 간에 승리를 보장하는 최소 비용을 반환하는 문제입니다.

<br>

## 풀이
정답 숫자를 이분 탐색을 통해 최소한의 비용으로 찾아야 하는데, 보장된 비용을 구해야 합니다. 따라서 2차원 dp를 활용합니다.
- dp[left][right]: 정답이 [left, right] 안에 있을 때 반드시 맞히기 위해 필요한 최소 보장 비용
- dp[x][x]는 숫자가 하나뿐이므로 비용 0
- ex) dp[2][3]: 3이 정답일 때 2만 지불하면 됨, 2가 정답이면 바로 정답 => 최소 보장 비용은 2
- 점화식: dp[left][right]
    = min(
        pick + max(
            dp[left][pick - 1],
            dp[pick + 1][right]
        )
      );
